# Audit-Trail-2.0 — Frontend

Modern, high-performance UI built with **React**, **Vite**, **Tailwind CSS**, and **Lucide Icons** for real-time logistics auditing, cryptographic event inspection, and AI dispute resolution.

---

## Quick Start (Hour 1 Setup)

From the project root or `frontend` directory:

```bash
# 1. Navigate to frontend
cd frontend

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

The application will be accessible at `http://localhost:5173`.

---

## Features
- **Dark & Light Mode**: Seamless theme toggle in the navigation bar with system preference detection and localStorage persistence.
- **Enterprise Typography & UI**: Zero emoji clutter; built with clean SVG icons from Lucide React and Inter typography.
- **Tamper-Evident Ledger**: Interactive SHA-256 block ledger with integrity verification and live tamper simulation.
- **AI Risk Center**: Continuous telemetry anomaly detection (temperature excursions, dwell time bottlenecks, route deviations).
- **Dispute Desk**: Automated evidence dossiers and liability determination backed by non-repudiable audit proofs.
- **FastAPI Proxy**: Pre-configured `/api` proxy targeting the backend at `http://127.0.0.1:8000`.
